# 💱 Currency Converter

A responsive and interactive Currency Converter web application that allows users to convert currencies using live exchange rates. The application provides a modern UI with currency swapping, conversion history, favorites, dark mode, and historical exchange-rate visualization.

## 🌐 Live Demo

🚀 **[Click here to use the Currency Converter](https://swathiancha08.github.io/Currency-Converter/)**

## 📂 GitHub Repository

🔗 **[View Source Code](https://github.com/swathiAncha08/Currency-Converter)**

## ✨ Features

- 💱 Convert between multiple currencies
- 🌐 Live exchange-rate API integration
- 🔄 Swap From/To currencies
- 🚩 Currency flags for easy identification
- ⚡ Quick amount buttons
- ⭐ Save favorite currency pairs
- 🕘 View recent conversion history
- 🌙 Dark mode
- 📊 Historical exchange-rate chart
- 📱 Responsive design for mobile and desktop
- ✨ Animated colorful background
- ⚠️ Loading and error handling

## 🔌 API

This project uses the **Frankfurter API** to retrieve exchange-rate data.

API:

https://api.frankfurter.dev/

The application fetches exchange rates dynamically and calculates the converted amount based on the selected currencies.
